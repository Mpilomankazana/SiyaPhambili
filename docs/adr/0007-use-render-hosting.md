# 7. Use Render for Hosting

**Status:** Accepted
**Date:** 2026-09-06

**Context:** We need a reliable cloud platform to host both a static frontend application and a live backend API simultaneously, with fast global content delivery.
**Decision:** We will use Render for our deployment infrastructure.

**Consequences:** 
* Provides automated, zero-downtime deployments directly from GitHub.
* Simplifies the delivery process for the final hackathon presentation.
