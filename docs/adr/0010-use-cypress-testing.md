# 10. Use Cypress for Acceptance Testing

**Status:** Accepted
**Date:** 2026-09-06

**Context:** The hackathon requires the solution to be consumer-facing and hit TRL 4. We must prove that real user workflows function correctly end-to-end.
**Decision:** We will use Cypress for acceptance testing.

**Consequences:** 
* Provides visual, in-browser testing to validate business needs.
* Adds heavier dependencies to the frontend structure.
