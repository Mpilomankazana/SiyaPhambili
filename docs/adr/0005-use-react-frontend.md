# 5. Use React for Frontend UI

**Status:** Accepted
**Date:** 2026-09-06

**Context:** The platform requires a responsive, consumer-facing interface that can quickly display dynamic civic innovation data without page reloads.
**Decision:** We will use React as our frontend library, combined with Material-UI components.

**Consequences:** 
* Enables a component-driven architecture for fast hackathon development.
* Requires managing global state (e.g., using React Context) for user sessions and filters.
